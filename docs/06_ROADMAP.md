# Roadmap — marcos condicionais, não calendário rígido

| Janela | Objetivo | Critério de saída |
|---|---|---|
| Semanas 1–2: Discovery | conceito, 10 comparáveis, 10–20 feedbacks, pitch, storyboard, licenças | Gate 0 aprovado |
| Semanas 3–4: Vertical slice | jogo com 3 minutos de loop original, cliente mobile, testes de servidor | 5 testes de usuário completos sem assistência |
| Semanas 5–6: Alpha | perfil persistente, progressão, conteúdo inicial, co-op simples se relevante | bugs críticos = 0; primeira sessão entendida |
| Semanas 7–8: Beta privada | QA, performance, telemetria, compliance, economia e primeira loja limitada | coortes de D1/D7 iniciais e feedback |
| Pós-beta: Soft launch | testar thumbnail/FTUE/conteúdo com tráfego moderado | benchmark/retorno suficiente para ampliar investimento |

## Gate 1 (fun)
Ao menos 5 usuários novos completam objetivo de 3 min sem explicação, relatam o que fazer e demonstram motivação de continuar.

## Gate 2 (retention)
D1/first-bounce e tempo de sessão comparados com benchmark oficial e seus intervalos de confiança; se insuficientes, iterar FTUE/core loop antes de anúncios.

## Gate 3 (unit economics)
Conversão e receita por DAU medidas, custos externos e margens estimadas, verificações de políticas encerradas. Se resultados negativos, não escalar aquisição paga.
